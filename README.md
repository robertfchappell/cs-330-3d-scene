# cs-330-3d-scene
Reflection on CS 330 Module Eight Journal

 To design the software for this project, I broke the 3D scene down into smaller parts and thought about how each object, texture, and camera feature fit into the bigger picture.  Taking this course helped me improve my design skills, especially when it comes to transformations, functions that can be reused, and planning 3D models utilizing basic shapes.  I looked at the reference image, mapped it to forms, and then improved each part by trying out different camera controls, lighting, and textures over and over again.  I can use these strategies—starting simple, breaking things down into smaller parts, and getting better with each iteration—in any future development job.  When I make programs, I try to build the main parts first and then add features on top. This was especially necessary for this project because I added navigation, lighting, and object organization one at a time.  Iteration was incredibly important; almost everything needed to be tested, tweaked, and fixed until the final scene felt like it all fit together.  As I reached each milestone, my development process grew more organized, and I learnt how crucial it is to keep things organized and use modular code when projects get more complicated.  Computer science helps me attain my goals by teaching me how to solve problems better and offering me real-world experience that is directly related to software development.  Working with computational graphics has helped me better grasp how rendering, lighting, shaders, and 3D math operate. This will help me in school and at work, especially as I progress further into software engineering and possibly game or visualization creation.  This was the hardest class I've ever attended. It was quite hard, but it made me learn more than any other class and helped me feel more confident in making complicated interactive systems.
